Operating Systems & Algorithms

Round Robin CPU Scheduling Performance Analyzer

This project investigates CPU scheduling behavior under realistic conditions by implementing a custom discrete-event simulation engine in Python. Rather than assuming instantaneous context switching, the simulation explicitly factors in context-switch overhead across varying quantum slices (q = 1ms to 20ms) for 100 randomized processes.

Key Technical Highlights:

  • Overhead Quantification: Evaluated how CPU thrashing degrades performance when time quanta approach context switch duration.
  • Metric Extraction: Automatically derived Average Turnaround Time (TAT) and Average Waiting Time (AWT).
  • Empirical Recommendation: Established the optimal quantum threshold that balances responsive times with minimal scheduling overhead.
Database Engineering & SQL

Database Concurrency Control Simulator

An experimental study evaluating multi-user concurrency and data integrity within relational database engines (MariaDB/MySQL). The project demonstrates how transaction isolation levels influence execution anomalies through parallel session scripts executing simultaneous reads and writes.

Key Technical Highlights:

  • Phenomena Reproduction: Successfully simulated and logged Dirty Reads, Non-Repeatable Reads, and Phantom Reads.
  • Isolation Analysis: Tested performance and lock contention across READ UNCOMMITTED, REPEATABLE READ, and SERIALIZABLE.
  • Concurrency Strategy: Formulated architectural guidelines for high-throughput transactional applications requiring ACID compliance.

C++ & OpenGL (FreeGLUT) Game Development

2D Eco-Shooter Game: Ocean Cleaner

A classic 2D retro arcade shooter developed from scratch using C++ and OpenGL . Centered around ocean conservation, players control a submarine cannon at the seabed to clear falling municipal and industrial waste from the surface, merging engaging interactive play with ecological awareness.

Key Technical Highlights:

  • Custom Collision Engine: Engineered a raw mathematical 2D circle-to-circle and bounding-box collision detection matrix from scratch, eliminating third-party library footprints.
  • Audio Context & Multi-threading Emulation: Fully integrated SDL_mixer to handle background spatial music loopings, shooting soundscapes, and scoring trigger playbacks safely compliant with browser user-interaction security guidelines.
